Regras de Uso
05 / REGRAS DE USO
Coerência pixel-perfect. Quando em dúvida, mais simples ganha.
  • Sempre desligar antialiasing: font-smooth: never + image-rendering: pixelated.
  • Bordas sempre 1 ou 2px. Nunca 1.5px, nunca border-radius. Cantos retos.
  • Sombras: offset fixo 2-3px na cor da tinta. Sem blur, sem alpha.
  • Grid base 8px. Múltiplos de 8 para padding, gap e altura de linha.
  • Ícones SVG inline com shape-rendering="crispEdges". Sem path curvo suave.
  • Dithering checker 2×2 só pra meio-tom real. Não como enfeite.
  • Copy neutro PT-BR: Rolar, Limpar, Ajustes, Histórico, Presets.
GRID 8PX
Espaçamentos sempre múltiplos de 8.
DITHER CHECKER 2×2
Use só pra indicar sombra ou meio-tom.
