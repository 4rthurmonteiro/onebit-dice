★ RECOMENDAÇÃO VARIANTE A (M1) → VARIANTE C (M2)

Para o Milestone 1, adotar a Variante A — Lista Vertical como implementação definitiva do bottom sheet. A lista é a solução mais fiel à estética 1-bit (apenas bordas e inversão), exige zero assets extras, e a área de toque de 44 px por linha garante conforto em qualquer tamanho de tela. O estado selecionado com inversão total + checkmark pixel é inequívoco e acessível.

A Variante B — Grade deve ser descartada para M1: os ícones SVG poligonais introduzem complexidade visual desnecessária que rivaliza com o dado principal na tela de rolagem, quebrando o princípio de hierarquia única. Pode ser reavaliada se futuros user-tests indicarem que usuários iniciantes não reconhecem os dados pelo nome.

A Variante C — Recentes + Grade é a evolução natural para M2 após o tracking de histórico estar implementado. A linha de "recentes" com chips oferece atalho de um toque para usuários de RPG (sessão com D20/D6 fixos) sem esconder os demais tipos. A duplicação do estado selecionado (chip + célula) é uma vantagem ergonômica que justifica a complexidade extra — mas depende de persistência de dados que só estará disponível com o módulo de histórico.

  • FECHAR 3 gestos suportados: tap fora do sheet (toca a hachura), arrastar drag-handle para baixo, botão ✕ pixel. Todos os 3 devem ser implementados mesmo que o ✕ seja escondido por padrão — acessibilidade exige fallback por toque.
  • OVERLAY Hachura 4×4 xadrez preta/branca (50 % dos pixels = preto) — equivalente visual a um semitransparente de 50 % sem usar opacidade ou cor cinza. Nenhum rgba() permitido.
  • ANIMAÇÃO Sheet desliza de baixo para cima em 200 ms, curva linear — sem easing suave (quebraria a estética rígida). Hachura aparece com o sheet (sem fade separado).
  • DRAG HANDLE 4 blocos de 8×4 px com gap de 3 px — pixel art puro. Não usar border-radius. Centralizado horizontalmente, padding-top de 8 px acima do título.
  • TIPOGRAFIA Labels principais: Press Start 2P 8–9 px. Sub-labels (lados, nome técnico): Silkscreen 10–11 px. Tudo CAIXA ALTA.
